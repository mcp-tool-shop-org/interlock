# Security

switchyard 0.1.x is a local advisory router, and it is a prototype. It serves no network traffic, reads no ledger, and never calls offrig. A route is a suggestion from the measured table. It does not start a device.

## Supported versions

0.1.x.

## Reporting a vulnerability

Use a GitHub private advisory on [mcp-tool-shop-org/switchyard](https://github.com/mcp-tool-shop-org/switchyard/security/advisories/new). Do not open a public issue for a vulnerability.
